# メモ・TODO・カレンダーアプリ

HTML、CSS、JavaScriptを使用して作成した、
メモ・TODO・カレンダーをまとめたWebアプリです。

## 機能

### メモ

・ メモの追加
・ メモの削除
・ メモ内容の自動保存
・ LocalStorageによるデータ保存

### TODO

・ TODOの追加
・ TODOの削除
・ TODOの完了・未完了の管理
・ 完了したTODOの表示
・ 未完了のTODOの表示
・ LocalStorageによるデータ保存

### カレンダー

・ 月の切り替え
・ 日付ごとのメモ
・ 日付ごとのメモの保存
・ LocalStorageによるデータ保存

## 使用技術

・ HTML
・ CSS
・ JavaScript
・ LocalStorage

## 制作目的

JavaScriptの学習として、DOM操作やイベント処理、配列・オブジェクト、LocalStorageなどを実際のアプリ開発を通して学ぶために制作しました。
